# CSS Advanced

This project focuses on advanced CSS concepts and techniques used to style modern web pages.

## Learning Objectives

By the end of this project, I should be able to explain:

- Selectors, properties, and values
- The difference between block and inline styling
- How to ensure consistency across browsers
- How to set up and use CSS variables
- The differences between inline, embedded, and external CSS
- How grid systems work
- The difference between icon webfonts and SVG icons
- The difference between pseudo-classes and pseudo-elements
- How to create background gradients
- How to animate elements with CSS
- How to transform elements in 2D and 3D
- What vendor prefixes are
- How to use custom font families
- How to manage font sizes and font weights with CSS variables

## Project Structure

The `styles` directory contains the CSS files created throughout the project.
