# HTML Advanced

This project focuses on learning the fundamentals and advanced concepts of HTML.

## Learning Objectives

By the end of this project, I should be able to explain:

- What HTML is
- How to create an HTML page from a wireframe
- What a markup language is
- What the DOM is
- What an element and a tag are
- What attributes are
- The purpose of each HTML tag
- How to structure a web page using semantic HTML
- The importance of HTML standards
